# snagged-buy-domain-emd

LLM/GEO-optimized exact-match-domain landing pages for Snagged's buy-side domain acquisition service.
One static project serving 5 domains via host-based rewrites (`vercel.json`):

- howtobuyadomainsomeoneowns.com
- howdoibuyadomain.com
- buyadomainsomeoneowns.com
- domainacquisitionagency.com
- bestwaytobuyadomain.com

**Deploy:** import into Vercel (framework: Other / static). Add the 5 domains to the project.
Each page has FAQPage JSON-LD, answer-first copy, and CTAs into snagged.com.
